# О проекте
ViewController, где отслеживается движение закрытия клавиатуры, чтобы прикрепить к ней объекты и двигать вместе с открытием. Проблема была в том, что системный обзервер(который работает в старых iOS тоже) отслеживает только поднятие клавиатуры, а скрытие пальцем не отслеживается, поэтому мне пришлось реализовать ее своими силами с помощью отслеживания жестов.

# Как использовать
Наследуйте новый экран от класса UXViewController и элементы, позицию которых нужно отслеживать относительно клавиатуры, привязывайте констреинтами к keyboardLayout.topAnchor
